# OAM Studio
One Stop Artist Marketing Studio — free static/PWA app for GitHub Pages.

## Current build
- Invoice & Quote PDF generator uses the approved OAM Studio master layout.
- Invoice and Quote use their own document number/date labels.
- Logo is inserted from OAM Studio settings without stretching.
- PO Number is supported on both Quotes and Invoices.
- Client VAT Number, event date, payment terms and banking details are supported.
- Quote → Invoice conversion keeps the original quote saved and marks it Converted.
- Quote Close/Delete actions remain available.
- Home includes New Invoice and New Quote.
- Works as a static web app/PWA on iPhone, Android and PC.

Deploy the contents of this folder to GitHub Pages. No paid backend is required for the included offline/local-storage features.
